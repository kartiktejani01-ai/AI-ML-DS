# Customer Churn Analysis using AI & Data Science

## 1. Definition
Customer churn analysis is the process of analyzing customer data to identify customers who may stop using a company's products or services.

## 2. Objective
- Analyze customer behavior
- Find churn patterns
- Predict churn using Machine Learning
- Identify important churn factors
- Support customer retention decisions

## 3. AI Features
1. Churn prediction
2. Churn risk probability
3. Pattern detection
4. Feature importance
5. Predictive analytics
6. AI-based retention recommendation

## 4. Technologies
Python, Pandas, Matplotlib, Scikit-learn, Random Forest

## 5. Step-by-step workflow
1. Collect customer data
2. Load CSV
3. Inspect data
4. Check missing and duplicate values
5. Perform statistical analysis
6. Visualize churn
7. Encode categorical data
8. Select features and target
9. Split training/testing data
10. Train Random Forest model
11. Evaluate accuracy and classification metrics
12. Analyze feature importance
13. Predict a new customer's churn
14. Generate a simple retention recommendation

## 6. Run
Install:
pip install pandas matplotlib scikit-learn

Then:
python customer_churn_analysis.py

## 7. Files
- customer_churn.csv: sample dataset
- customer_churn_analysis.py: complete project code
